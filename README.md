# Portfolio Dhiyaulhaq

Personal portfolio website built with **Next.js** and **Tailwind CSS**. Designed as an editorial, magazine-style layout to showcase products, skills, certificates, and professional experience.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (editorial design)
- **Typography:** Fraunces, Newsreader & JetBrains Mono via `next/font`
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## ✨ Key Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop.
- **Editorial UI:** Warm paper tones, serif display type, a single accent color, and ruled, magazine-like sections.
- **Product Showcase:** Shaka Studio and Compile Daily.
- **Certificates Archive:** Searchable, filterable list of certifications (Dicoding, Google, Udemy, hackathons, etc.) with image preview and PDF.
- **Record:** Education, work, and hackathon timeline.
- **Documentation:** Photo essay from events and hackathons.

## 📂 Project Structure

```text
├── app/              # Next.js App Router (Pages & Layouts)
│   └── sitemap.ts    # Auto-generated sitemap
├── components/       # Reusable UI Components (Hero, About, Skills, etc.)
├── data/             # Site content: products, record, skills, certificates
├── public/           # Static assets (Images, CV, Certificates)
└── tsconfig.json     # TypeScript configuration
```

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HaqiKuy470/Dhiyaulhaq.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3008](http://localhost:3008) (Default port configured in `package.json`)

4. **Build for production:**
   ```bash
   npm run build
   ```
